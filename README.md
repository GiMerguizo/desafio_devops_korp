# Teste DevOps - Korp
Esse desafio visa avaliar suas habilidades com Docker, programação, redes, servidores e
automação em ambiente Linux, por meio da construção de um serviço simples em Golang e da
infraestrutura necessária para sua execução em containers, com ênfase posterior em automação
com Ansible. <br>

## Cheklist do Desafio
- [ ] Serviço HTTP1
- [ ] Instalação e Configuração do Docker
- [ ] Configuração de Rede Docker    
- [ ] Docker Compose
- [ ] Configuração do Proxy Reverso
- [ ] Teste de Funcionamento
- [ ] Prometheus
- [ ] Grafana
  - [ ] Dashboard
- [ ] Automação com Ansible
